# Smart home

## Home Assistant

Home Assistant is the automation/backend layer while Google Home remains usable for voice and household familiarity.

Confirmed integrations:

- Google Cast (Nest Hubs, TV)
- Sony KD-65AF9 Android TV Remote
- Sonos Era 300
- Music Assistant

Deferred:

- Matter integration/server
- Google Nest Doorbell via SDM
- optional FRITZ!Box monitoring

## Matter principle

Existing Matter devices should not be casually removed from Google Home. When added to Home Assistant, use a multi-admin/share approach where possible so existing household behavior remains intact.
